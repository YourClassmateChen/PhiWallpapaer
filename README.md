PhiWallpaper——Dynamic wallpaper software based on Python

## Brief Introduction

Turn your video into a dynamic wallpaper with the simplest solution!<br>
Just one MP4 file, and make your wallpaper come alive!

## About PhiWallpaper

To get the application, please download the archive from the release page.<br>
To get the source code, clone this repository to your local machine.<br>
User Guide: <a href="http://106.53.213.36/信息技术の教程/phiwallpaper使用指南">Wordpress Blog - PhiWallpaper User Guide</a><br>
Currently adapted for Windows 11-24H2-26000 updates.<br>
The latest version is compatible with Windows 10 / Windows 11.<br>
After launching the program, please check the system tray.
